## Descrição do projeto

O projeto "SoundFeel" é uma landing page criada para conectar emoções e música. A ideia principal é permitir que o usuário registre como está se sentindo no momento e descubra faixas que combinem com esse estado emocional. A página apresenta uma estética moderna, navegação direta e uma estrutura visual voltada para uma experiência agradável e intuitiva.

A interface contém elementos como cabeçalho com menu, seção hero com chamada principal, cards com emoções, área de registro e explicação de funcionamento. O objetivo é transmitir uma proposta de aplicativo/serviço emocional que ajuda as pessoas a expressarem seu humor e encontrarem trilhas sonoras adequadas.
